# po-workbench 项目简介

## 一句话

企业内部使用的「采购订单采集工作台」：把各家企业发来的采购订单收集进来、核对检查、存进订单库。

## 现在能做什么（v0.1.0）

- **工作台概览页**（`/dashboard`）：今日采集、待审核、已入库、异常订单四个指标卡片，加采集任务面板和最近订单列表。数据目前是占位示例。
- **采购订单采集页**（`/collection`）：采集入口按钮还是禁用状态，页面上写明了规划中的流程——配置数据源 → 获取订单数据 → 数据校验 → 写入订单库。
- **基础上设施**：404 页面、全局错误边界、冒烟测试。

## 技术栈（一句话）

React 19 + TypeScript + Ant Design 6 + Vite 6，纯前端项目；本地开发用 `npm run dev`，默认地址 `http://localhost:5173`。

4. 订单审核、异常处理、导出

## 环境要求

Node.js `20.19+` 或 `22.12+`。用 nvm 的话可执行 `nvm use 22`（项目自带 `.nvmrc`）。Node 18 跑测试会报错。
